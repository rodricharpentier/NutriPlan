# NutriPlan

**NutriPlan** es una aplicación de escritorio desarrollada en **Python** utilizando **wxPython**. El proyecto fue realizado como Trabajo Final para la materia **Programación Orientada a Objetos**.

La aplicación permite generar un plan alimentario básico a partir del nombre, la edad y el tipo de dieta seleccionado por el usuario.

## Funcionalidades

* Generación de un menú para dieta normal.
* Generación de un menú para dieta celíaca.
* Generación de un menú para dieta vegana.
* Validación de los datos ingresados.
* Interfaz gráfica desarrollada con wxPython.

## Tecnologías utilizadas

* Python 3
* wxPython

## Ejecución

1. Descargar o clonar este repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo:

```bash
python3 NutriPlan.py
```
